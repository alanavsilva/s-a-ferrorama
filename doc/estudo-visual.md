#  Identidade visual do sistema

### cores, tipografia, estilo, referências visuais e proposta de layout

#### Cores
A cor foi decidida pela equipe para dar uma identidade visual ao site, principalmente pela escolha estratégica para transmitir estabilidade, conforto e confiança, para o tortar bem marcante foram utilizados tons de marrom e branco

#### Tipografia
 Foi ultilizada a fonte padrão do html "sans-serif", já que foi a escolhida no projeto 
Guiamos a leitura e destacamos informaçãoes importantes com o uso de tamanhos, pesos (negrito, regular, light) e cores

#### Estilo
Prezamos pela funcionalidade e Rapidez, Informações Completas e Design Acessível: Layouts organizados para facilitar a visualização de rotas e baldeações.

#### Referências visuais 
Inspirado no click bus, foram utilizados o cabeçalho, tela de login e explorar como referência

#### Proposta de layout 
O layout foi proposto para ter informaçôes completas e organizadas para facil entendimento e facilidade para navegar em nosso site
